# Completion audit

## Status vocabulary

- `repository_evidence_present`: exact tracked code/config, tests, and deterministic repository artifacts exist.
- `committed_synthetic_evidence`: immutable local CPU evaluation artifacts pass checksum and recomputation checks.
- `controller_final_live_gate`: exact implementation and test paths exist, but service-backed acceptance still requires a fresh controller command. Synthetic reports do not satisfy this status.

Each matrix row has a stable ID. Code/config and test cells name exact tracked files. The artifact/runtime/report cell names the exact committed artifact or executable gate; the ignored one-shot lock is the only explicitly local path. `scripts.verify_repository` validates the full ID set, required paths by category, path existence/tracking, and the declared status.
